JDK 21, no dependencies. Run from the handbook root:

```
java -Dstdout.encoding=UTF-8 labs/ch59-qa-bank/QaBankL1.java docs /tmp/bank   # L1+L2: bank_starred.md, index_all.md, coverage table
java -Dstdout.encoding=UTF-8 labs/ch59-qa-bank/DrillL3.java docs B3 20260930  # L3: 12-question drill (band, seed)
java -Dstdout.encoding=UTF-8 labs/ch59-qa-bank/SpacedL4.java                  # L4: study-plan simulation
```

To refresh the site pages, copy `bank_starred.md` below the header of `docs/07-interview/qa-bank-starred.md` and `index_all.md` below the header of `docs/99-appendix/qa-index.md`.
`*_out.txt` are the outputs quoted in the chapter.
