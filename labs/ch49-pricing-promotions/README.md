# Ch 49 labs — Pricing, Promotions & Coupons

JDK 21, no dependencies. Run each with `java -Dstdout.encoding=UTF-8 <File>.java`.

| Lab | File | Output |
|---|---|---|
| L1 money, allocation, refunds | MoneyL1.java | money_out.txt |
| L2 promotion engine (index + combination policy) | PromoEngineL2.java | promo_out.txt |
| L3 campaign budget pacing & uplift targeting | BudgetPacingL3.java | pacing_out.txt |
| L4 perishable markdowns | MarkdownL4.java | markdown_out.txt |

Fixed seeds; L2 timings vary by machine. GST rates, coupon response and markdown response models are illustrative
assumptions — verify with finance/tax and your own experiments.
