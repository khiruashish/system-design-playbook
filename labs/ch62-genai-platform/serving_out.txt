C. Long-context requests (order history + documents, ~9,000-token prompts): memory per request is 3x larger
   policy                                    max req/s/GPU   max concurrent
   continuous batching, reserve 16k KV                2.25               28
   continuous batching, paged KV                      3.25               49
   paged KV + prefix cache                            3.75               45

   -> the model is the same in every row: scheduling alone changes how many GPUs you buy.
     Static batches wait for their slowest member; continuous batching admits work every iteration.
     Paged KV memory raises concurrency; prefix caching skips re-reading the 1,200-token system prompt.
