    1. URL Shortener Core: Base62 & Id Allocation¶

    L1 ★★☆ · Base62 encode/decode, id allocation, custom aliases, overflow safety

    Problem¶

    Implement the core of a URL shortener: turn a numeric id into a short base62 code and back, deduplicate long URLs, support custom aliases without collisions, and resolve codes for redirects.

    Key idea¶

    Don't hash and hope for no collisions. Allocate a unique id (a DB sequence, or per-node ranges from a counter service), then base62-encode it. Seven characters cover 62⁷ ≈ 3.5 trillion URLs. Custom aliases live in the same keyspace and are claimed atomically (putIfAbsent here; INSERT ... ON CONFLICT in a DB). Reads dominate (about 100:1), so resolve is a key lookup behind a cache.

    flowchart LR C[POST /shorten] --> ID["id allocator<br/>(range per node)"] --> E["base62(id) → 6LAze"] --> DB[(code → url)] R[GET /6LAze] --> CA{cache} -->|miss| DB CA -->|hit| RD[301/302 redirect]

    Solution¶

    UrlShortener.java
    import java.util.*;

/** Problem: design the core of a URL shortener: id generation, base62 codes, custom aliases, redirect lookup. */
public class UrlShortener {

    private static final String ALPHABET = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";

    static String encode(long id) {
        if (id == 0) return "0";
        StringBuilder sb = new StringBuilder();
        while (id > 0) { sb.append(ALPHABET.charAt((int) (id % 62))); id /= 62; }
        return sb.reverse().toString();
    }

    static long decode(String code) {
        long id = 0;
        for (char c : code.toCharArray()) {
            int digit = ALPHABET.indexOf(c);
            if (digit < 0) throw new IllegalArgumentException("invalid code " + code);
            id = Math.multiplyExact(id, 62) + digit;          // overflow-safe for hostile input
        }
        return id;
    }

    static final class Shortener {
        private long nextId;                                   // production: DB sequence / range allocator per node
        private final Map<String, String> codeToUrl = new HashMap<>();
        private final Map<String, String> urlToCode = new HashMap<>();   // optional: same long URL -> same code

        Shortener(long startId) { this.nextId = startId; }

        synchronized String shorten(String url) {
            validate(url);
            return urlToCode.computeIfAbsent(url, u -> { String code = encode(nextId++); codeToUrl.put(code, u); return code; });
        }

        synchronized String shortenWithAlias(String url, String alias) {
            validate(url);
            if (!alias.matches("[A-Za-z0-9_-]{3,30}")) throw new IllegalArgumentException("alias must be 3-30 chars [A-Za-z0-9_-]");
            if (codeToUrl.putIfAbsent(alias, url) != null) throw new IllegalStateException("alias taken: " + alias);
            return alias;
        }

        /** 301 (permanent, cacheable by browsers) vs 302 (temporary, every click reaches us for analytics). */
        Optional<String> resolve(String code) { return Optional.ofNullable(codeToUrl.get(code)); }

        private static void validate(String url) {
            if (!url.startsWith("https://") && !url.startsWith("http://")) throw new IllegalArgumentException("not an http(s) URL");
        }
    }

    public static void main(String[] args) {
        System.out.println("encode(125)        = " + encode(125) + "   (125 = 2*62 + 1)");
        System.out.println("encode(3.5 trillion) = " + encode(3_521_614_606_207L) + " (7 chars cover 62^7 = 3.5e12 URLs)");
        for (long id : new long[]{0, 61, 62, 999_999_999_999L}) check(decode(encode(id)) == id, "round trip " + id);

        Shortener s = new Shortener(100_000_000L);            // start high so codes are not 1-2 chars and guessable-sequential
        String a = s.shorten("https://example.com/articles/2025/system-design?ref=newsletter");
        String b = s.shorten("https://example.com/other");
        String again = s.shorten("https://example.com/articles/2025/system-design?ref=newsletter");
        String alias = s.shortenWithAlias("https://example.com/sale", "big-sale");
        System.out.println("short codes        = " + a + ", " + b + " (same URL again -> " + again + "), alias " + alias);
        System.out.println("resolve(" + a + ")       = " + s.resolve(a).orElse("404"));
        System.out.println("resolve(nope)      = " + s.resolve("nope").orElse("404"));
        try { s.shortenWithAlias("https://x.com", "big-sale"); } catch (IllegalStateException e) { System.out.println(e.getMessage()); }

        check(a.equals(again) && !a.equals(b), "dedupe + unique codes");
        check(s.resolve("big-sale").orElseThrow().endsWith("/sale"), "alias resolves");
        try { decode("zzzzzzzzzzzzzzzzzzzz"); check(false, "overflow"); } catch (ArithmeticException e) { System.out.println("decode of a 20-char code -> overflow detected"); }
        System.out.println("PASS");
    }

    static void check(boolean ok, String what) { if (!ok) { System.out.println("FAILED: " + what); System.exit(1); } }
}

    Walkthrough¶

    Code Why
    sb.append(ALPHABET.charAt((int) (id % 62))); id /= 62; ... reverse() Repeated division gives the digits least significant first, so reverse at the end.
    Math.multiplyExact(id, 62) + digit Decoding user-supplied codes must detect overflow. A 20-character code would wrap around silently with plain *.
    new Shortener(100_000_000L) Starting high avoids 1–2 character codes. Sequential codes are guessable, so if that matters, encode id XOR secret or shuffle the bits.
    urlToCode.computeIfAbsent(url, ...) The same long URL returns the same code (optional, and it needs a reverse index). Some products deliberately create a new code per user for analytics.
    codeToUrl.putIfAbsent(alias, url) != null → taken An atomic claim of the custom alias.

    Complexity¶

    Approach Time Space
    encode / decode O(code length) O(1)
    shorten / resolve O(1) map ops O(URLs)

    Solve it with Spring Boot 4¶

    The counter becomes Redis INCRBY in blocks so every instance can mint ids without a round trip per link, custom aliases are claimed with an atomic SET NX, and the redirect path is served from a Caffeine @Cacheable cache.

    sequenceDiagram participant C as Client participant A as ShortenerController participant S as ShortenerService participant I as IdBlockAllocator participant R as Redis C->>A: POST /api/v1/urls {url} A->>S: shorten(url, alias) S->>I: nextId() I-->>R: INCRBY shortener:id-block 1000 (once per 1,000 ids) S->>R: SET shortener:code:{base62(id)} url A-->>C: 201 Location: https://sho.rt/{code} C->>A: GET /s/{code} A->>S: resolve(code) [@Cacheable short-urls] S->>R: GET shortener:code:{code} (cache miss only) A-->>C: 302 Location: long URL
    ShortenerService.java
    package com.sdp.ci.p01shortener;

import com.sdp.ci.common.Problems;
import org.springframework.cache.annotation.Cacheable;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;

@Service
public class ShortenerService {
    static final String CODE_KEY = "shortener:code:";
    private final StringRedisTemplate redis;
    private final IdBlockAllocator ids;

    public ShortenerService(StringRedisTemplate redis, IdBlockAllocator ids) {
        this.redis = redis;
        this.ids = ids;
    }

    /** Custom alias: SET NX makes "claim this alias" atomic, so two users can't both get it. */
    public String shorten(String longUrl, String alias) {
        if (alias != null) {
            Boolean claimed = redis.opsForValue().setIfAbsent(CODE_KEY + alias, longUrl);
            if (!Boolean.TRUE.equals(claimed)) throw Problems.of(HttpStatus.CONFLICT, "alias '" + alias + "' is taken");
            return alias;
        }
        String code = Base62.encode(ids.nextId());
        redis.opsForValue().set(CODE_KEY + code, longUrl);
        return code;
    }

    /** Hot read path: served from the local Caffeine cache ("short-urls"), then Redis. Links are immutable, so caching is safe. */
    @Cacheable("short-urls")
    public String resolve(String code) {
        String url = redis.opsForValue().get(CODE_KEY + code);
        if (url == null) throw Problems.of(HttpStatus.NOT_FOUND, "no link for code '" + code + "'");
        return url;
    }
}
    IdBlockAllocator.java
    package com.sdp.ci.p01shortener;

import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Component;

/**
 * Hands out unique ids without a Redis round trip per id: each instance reserves a block of
 * {@code idBlockSize} ids with one atomic INCRBY, then serves them from memory.
 * Ids stay unique across instances; a crash only wastes the unused rest of a block.
 */
@Component
public class IdBlockAllocator {
    static final String KEY = "shortener:id-block";
    private final StringRedisTemplate redis;
    private final int blockSize;
    private long next = 0, end = 0;          // current block is [next, end)
    private int blocksReserved = 0;

    public IdBlockAllocator(StringRedisTemplate redis, ShortenerProperties props) {
        this.redis = redis;
        this.blockSize = props.idBlockSize();
    }

    public synchronized long nextId() {
        if (next >= end) {
            long high = redis.opsForValue().increment(KEY, blockSize);   // atomic across all instances
            next = high - blockSize + 1;
            end = high + 1;
            blocksReserved++;
        }
        return next++;
    }

    public synchronized int blocksReserved() { return blocksReserved; }
}
    ShortenerController.java
    package com.sdp.ci.p01shortener;

import jakarta.validation.Valid;
import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.Pattern;
import java.net.URI;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
public class ShortenerController {
    public record ShortenRequest(
            @NotBlank @Pattern(regexp = "https?://\\S+", message = "must be an http(s) URL") String url,
            @Pattern(regexp = "[A-Za-z0-9_-]{4,30}", message = "4-30 letters, digits, _ or -") String alias) {}

    public record ShortenResponse(String code, String shortUrl, String url) {}

    private final ShortenerService service;
    private final ShortenerProperties props;

    public ShortenerController(ShortenerService service, ShortenerProperties props) {
        this.service = service;
        this.props = props;
    }

    @PostMapping("/api/v1/urls")
    public ResponseEntity<ShortenResponse> shorten(@Valid @RequestBody ShortenRequest req) {
        String code = service.shorten(req.url(), req.alias());
        String shortUrl = props.baseUrl() + code;
        return ResponseEntity.created(URI.create(shortUrl)).body(new ShortenResponse(code, shortUrl, req.url()));
    }

    /** 302 (not 301) so browsers keep coming back and every click can be counted. */
    @GetMapping("/s/{code}")
    public ResponseEntity<Void> redirect(@PathVariable String code) {
        return ResponseEntity.status(HttpStatus.FOUND).location(URI.create(service.resolve(code))).build();
    }
}
    Base62.java
    package com.sdp.ci.p01shortener;

/** Same algorithm as the interview solution: bijective base62 over non-negative longs. */
public final class Base62 {
    private static final String ALPHABET = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";
    private Base62() {}

    public static String encode(long id) {
        if (id < 0) throw new IllegalArgumentException("id must be >= 0");
        if (id == 0) return "0";
        StringBuilder sb = new StringBuilder();
        while (id > 0) { sb.append(ALPHABET.charAt((int) (id % 62))); id /= 62; }
        return sb.reverse().toString();
    }

    public static long decode(String code) {
        long id = 0;
        for (char c : code.toCharArray()) {
            int d = ALPHABET.indexOf(c);
            if (d < 0) throw new IllegalArgumentException("not base62: " + c);
            id = Math.addExact(Math.multiplyExact(id, 62), d);
        }
        return id;
    }
}

    What changes from the interview version¶

    Interview Production (Spring Boot 4)
    long counter++ in one JVM INCRBY id blocks: unique across instances, 1 Redis call per 1,000 links
    HashMap alias check then put SET NX: claim-the-alias is atomic, so two users can't both win
    lookup in a map Caffeine cache in front of Redis (links are immutable, so no invalidation needed)
    return a string 201 Created + Location, 302 redirects, ProblemDetail for 400 / 404 / 409

    Trade-off to mention: sequential ids are guessable. Shuffle them (e.g. multiply by a constant modulo 62^7) or use random 7-character codes with SET NX retry if links must not be enumerable.

    Common mistakes¶

    • Using a hash of the URL (MD5 truncated to 7 characters) without handling collisions. With billions of URLs, birthday collisions are certain.
    • A single global counter as a bottleneck. Hand each node a block of ids (for example 1,000) at a time.
    • Not validating the target URL, which turns the service into an open-redirect and phishing tool.
    • Always returning 301. Browsers cache it permanently, so you lose click analytics. Use 302 if you need to count clicks.

    Follow-up questions¶

    How do you scale id generation across regions?

    Give each region or node its own range (a range allocator in ZooKeeper or a DB), or use Snowflake-style ids (problem 5). Base62 of a 64-bit Snowflake id is about 11 characters, which is longer but needs no coordination.

    How would you expire links and clean up?

    Store expires_at. The redirect path checks it (and the cache TTL is capped at it). A background job or DynamoDB/Cassandra TTL deletes expired rows. Don't reuse codes for a long time after they expire, to avoid confusion.
