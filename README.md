# System Design Playbook — chapter videos

This orphan branch holds only the narrated MP4 videos, one per chapter, so that `main` and the GitHub Pages
site stay small. The site embeds them from
`https://raw.githubusercontent.com/khiruashish/system-design-playbook/videos/<chapter path>.mp4`.
Captions (`.vtt`), posters and `manifest.json` live on `main` under `docs/videos/`.

Generated by `tools/videos/make_videos.py` on `main`. Clone without this branch:
`git clone --single-branch --branch main https://github.com/khiruashish/system-design-playbook`
